# 快速开始

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 |
| 运行时 | 使用自包含发布包时无需单独安装 .NET |
| 磁盘 | 建议预留足够空间存放 `apps` 目录中的绿色版软件 |
| 权限 | 进程管理一般无需管理员；Hosts 编辑需要管理员权限 |

## 安装

1. 在 [GitHub Releases](https://github.com/pengcunfu/devenv/releases) 下载 `DevEnv-x.x.x-win-x64.zip`。
2. 解压到任意目录（路径尽量不含中文与空格）。
3. 运行 `DevEnv.exe`。

## 主界面

- **顶栏**：软件下载、下载管理、环境扫描、镜像配置，以及「工具」下拉中的小工具入口。
- **中间**：绿色版服务进程列表，可对每项执行启动/停止。
- **底部**：左侧打开本帮助文档，右侧点击版本号查看关于信息。

## 数据目录

程序默认将下载与绿色版软件放在数据目录下（可在「工具 → 数据目录」中修改），典型结构：

```
D:\devenv\          （示例，以 config.json 为准）
├── apps\           # 各软件绿色包
├── config.json     # 应用配置
└── ...
```

首次使用建议先打开 **镜像配置**，按需设置 pip / npm 等国内镜像，再使用 **软件下载**。
