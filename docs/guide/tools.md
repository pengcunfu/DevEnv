# 小工具

通过主界面顶栏 **工具 ▾** 打开以下功能。

## JSON 格式化器

- 格式化或压缩 JSON 文本
- 适合查看 API 响应、调试配置文件

## Hosts 文件编辑器

- 文本模式与按条编辑模式
- 支持 IP 格式校验、备份

::: warning
修改 `hosts` 需要 **以管理员身份运行** DevEnv。保存后可在命令行执行 `ipconfig /flushdns` 刷新 DNS 缓存。
:::

## 图像格式转换器

- 批量转换图片格式
- 支持拖拽添加文件

## 文件哈希计算器

- 支持 MD5、SHA-1、SHA-256 等
- 可对文件或文本计算哈希并复制结果

## 应用目录 / 数据目录

- **应用目录**：在资源管理器中打开绿色版软件所在 `apps` 目录
- **数据目录**：打开并修改 DevEnv 根数据路径等设置
