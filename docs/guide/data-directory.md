# 数据目录

熔岩环境管理工具将下载的软件包、绿色版服务、配置等集中在**数据目录**。

默认根路径为用户「文档」下的提供商与程序目录：

```
文档\FNSoftware\DevEnv\
```

例如：`C:\Users\<用户名>\Documents\FNSoftware\DevEnv`。

其中 `FNSoftware` 为软件提供商目录，`DevEnv` 为本程序目录。可在 **工具 → 数据目录** 中查看实际路径，并通过编辑 `config.json` 调整 `cache_dir` / `apps_dir` 等子路径。

::: tip
若曾使用旧版默认目录 `D:\devenv`，可将其中内容整体复制到上述新路径后再启动。
:::

## 与进程的关系

- `apps` 下各子目录对应不同软件的解压结果。
- 进程配置中的可执行文件路径相对于数据目录解析。
- 迁移数据目录时，请整体复制原目录内容到新路径。
