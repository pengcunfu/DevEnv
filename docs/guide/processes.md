# 进程管理

DevEnv 通过**启动独立进程**的方式运行绿色版服务，而不是注册 Windows 服务，因此通常不需要管理员权限。

## 支持的服务

主界面列表中的程序由 `Resources/processes_config.json` 配置，常见包括：

- MySQL、PostgreSQL、Redis、MongoDB
- MinIO、Nginx、Kafka

具体以你使用的版本为准。

## 状态说明

| 状态 | 含义 |
|------|------|
| 未安装 | 未在应用目录中找到对应绿色包，需先通过软件下载安装 |
| 已停止 | 已安装且当前未运行 |
| 运行中 | 由 DevEnv 启动的进程 |
| 外部运行 | 检测到同名服务已在运行（非本工具启动） |

## 操作

1. 确认状态为「已停止」后，点击 **启动**。
2. 需要关闭时点击 **停止**。
3. 若启动失败，请检查：绿色包是否完整、端口是否被占用、日志路径是否可写。

## 提示

- 数据文件一般位于数据目录下各软件子文件夹，卸载绿色包前请自行备份。
- 修改 `processes_config.json` 后需重启 DevEnv 生效。
