# NetworkWatch

按进程展示 TCP/UDP 连接与上下行速率，并提供端口管理与一键测速。以 **Library** 形式位于 `libs/NetworkWatch/`，由 `DevBox.Core` 引用；界面在 DevEnv 的「网络监控」页。

## 源码位置

```
libs/NetworkWatch/
├── Models/
├── Services/
├── Native/
└── Helpers/
```

用户使用说明见在线文档：[网络监控](https://docs.devenv.cn/guide/networkwatch/getting-started)。
