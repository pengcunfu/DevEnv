# 熔岩翻译助手

多站点网页翻译模块，位于 `DevEnv.Core/Translator/`，独立翻译窗口由 `DevEnv.Host` 承载（WPF 外壳 + WebView2，全应用唯一保留 WebView2 的地方）；按 `Alt+Space` 全局热键或托盘菜单打开，剪贴板有文本时自动 DOM 填充。

## 源码位置

```
DevEnv.Core/Translator/
├── Models/                 # 站点与配置模型
└── Services/               # ConfigService、WebFillAutomation
```

用户使用说明见在线文档：[熔岩翻译](https://devenv.cn/guide/translator/getting-started)。
