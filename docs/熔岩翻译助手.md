# 熔岩翻译助手

多站点网页翻译模块，以 **Library** 形式被 `DevBox.Core` / `DevBox.Host` 引用。独立翻译窗口是 WPF 外壳 + WebView2（全应用唯一保留 WebView2 的地方）；`Alt+Space` 唤起，剪贴板有文本时自动 DOM 填充。

## 源码位置

```
libs/Translator/
├── Models/                 # 站点与配置模型
└── Services/               # ConfigService、WebFillAutomation
```

用户使用说明见在线文档：[熔岩翻译](https://docs.devenv.cn/guide/translator/getting-started)。
