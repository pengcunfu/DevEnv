# 熔岩翻译助手

多站点网页翻译模块，以 **Library** 形式被 `DevBox.Api` / `DevBox.Host` 引用。独立翻译窗口由 Host 托管 WebView2；`Alt+Space` 唤起，剪贴板有文本时自动 DOM 填充。

## 源码位置

```
Translator/Translator/
├── Models/                 # 站点与配置模型
├── Services/               # ConfigService、WebFillAutomation
└── Infrastructure/         # 启动项等（Avalonia UI 已停用）
```

用户使用说明见在线文档：[熔岩翻译](https://docs.devenv.cn/guide/translator/getting-started)。
