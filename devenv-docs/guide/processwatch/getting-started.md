# 进程监控 · 快速开始

「进程监控」内嵌于 DevBox 左侧 **进程监控** Tab，实时查看本机进程的 CPU、内存占用。

## 主界面

- **进程列表**：进程名、PID、CPU%、工作集内存、线程数、可执行路径
- **进程详情**：选中后查看路径、专用/虚拟内存、句柄、启动时间、响应状态
- **搜索**：按进程名、PID 或路径过滤
- **排序**：按 CPU、内存或名称排序
- **暂停 / 立即刷新**：暂停自动刷新（约每秒一次），或手动采集一次

## 操作

选中进程后可：

- **结束进程**：终止该进程（可能需要管理员权限）
- **结束进程树**：终止该进程及其子进程
- **打开目录**：在资源管理器中定位可执行文件（无路径时按钮禁用）

::: tip
结束系统关键进程可能导致不稳定。若提示权限不足，可尝试以管理员身份运行整个 DevBox。
:::

## 与网络监控的区别

| 模块 | 关注点 |
|------|--------|
| 进程监控 | CPU、内存、结束进程 |
| 网络监控 | TCP/UDP 连接、上下行速率、测速与端口管理 |
