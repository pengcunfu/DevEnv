# 熔岩环境 · 快速开始

「熔岩环境」是 DevBox 内嵌的绿色版开发环境管理模块，可在 Windows 上一键下载、配置与管理 MySQL、Redis、Nginx 等本地服务，并附带环境扫描与镜像配置。

::: tip
无需再单独安装 `DevEnv.exe` / LavaEnv 压缩包。打开 DevBox，切换到左侧 **熔岩环境** Tab 即可使用。
:::

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（与 DevBox 相同） |
| 运行时 | 随 DevBox 安装（.NET 10 Desktop Runtime） |
| 磁盘 | 建议预留足够空间存放 `apps` 目录中的绿色版软件 |
| 权限 | 进程管理一般无需管理员；Hosts 编辑（在「系统工具」中）需要管理员权限 |

## 打开方式

1. 安装并启动 [DevBox](https://github.com/pengcunfu/DevBox.Net/releases/latest)。
2. 在左侧导航选择 **熔岩环境**。
3. 顶栏提供软件下载、下载管理、环境扫描、镜像配置，以及「工具」下拉（环境变量 / 应用目录 / 数据目录）。

## 主界面

- **顶栏**：软件下载、下载管理、环境扫描、镜像配置，以及「工具」下拉。
- **中间**：绿色版服务进程列表，可对每项执行启动/停止。
- **底部**：左侧打开本帮助文档，右侧点击版本号查看关于信息。

JSON 格式化、Hosts 编辑等小工具请到左侧 **系统工具** Tab 的「实用工具」分类使用。

## 数据目录

熔岩模块的下载与绿色版软件默认放在独立数据目录（可在「工具 → 数据目录」中查看/修改），与 DevBox 自身的 `文档\FNSoftware\DevBox\` 分开：

```
文档\FNSoftware\DevEnv\     （默认；实际路径见「工具 → 数据目录」）
├── apps\                   # 各软件绿色包
├── cache\                  # 下载缓存
├── config.json             # 熔岩应用配置
└── ...
```

首次使用建议先打开 **镜像配置**，按需设置 pip / npm 等国内镜像，再使用 **软件下载**。
