# 熔岩剪贴板 · 快速开始

「熔岩剪贴板」内嵌于 DevBox 左侧 **熔岩剪贴板** Tab（原独立 Clipboard 应用），自动记录文本与图片剪贴板历史。

## 功能

- **自动监听**：启动 DevBox 后即在后台轮询剪贴板（可点「关闭监听」暂停）
- **历史列表**：按时间范围、类型（文本/图片）与关键词过滤
- **预览**：选中条目查看文本或图片；双击或点「复制」写回剪贴板
- **清空 / 导出**：按当天 / 一周 / 一月 / 全部清空；导出当前可见文本历史
- **全局热键**：默认 `Ctrl+Space`，唤起 DevBox 并切换到本 Tab（可在工具栏「快捷键」中修改）

## 数据目录

用户数据在文档目录：`文档\FNSoftware\Clipboard\`

| 文件 / 目录 | 说明 |
|-------------|------|
| `config.json` | 热键等配置 |
| `clipboard.db` | SQLite 历史库 |
| `clipboard_images/` | 图片文件 |

启动时会自动迁移旧位置（程序目录或 `data/`）中的数据。

## 与独立版差异

嵌入 DevBox 后：

- 不再使用独立托盘 / 开机自启 / 应用内自更新（由 DevBox 统一管理）
- 关于信息见 DevBox「设置」
- 热键唤起的是 DevBox 主窗 + 本 Tab，而非独立窗口
- 代码高亮预览简化为纯文本 + 语言识别标签
