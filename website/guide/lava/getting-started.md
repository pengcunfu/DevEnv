# 熔岩环境 · 快速开始

「熔岩环境」是 DevEnv 的绿色版开发环境管理模块，可在 Windows 上一键下载、配置与管理 MySQL、Redis、Nginx 等本地服务，并附带环境扫描与镜像配置。

::: tip
无需再单独安装 `DevEnv.exe` / LavaEnv 压缩包。打开 DevEnv，从启动器「内置工具 → 环境 → 熔岩环境」进入即可使用。
:::

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（与 DevEnv 相同） |
| 运行时 | 随 DevEnv 安装（.NET 10 Desktop Runtime） |
| 磁盘 | 建议预留足够空间存放 `apps` 目录中的绿色版软件 |
| 权限 | 进程管理一般无需管理员；Hosts 编辑（在「系统工具」中）需要管理员权限 |

## 打开方式

1. 安装并启动 [DevEnv](https://github.com/pengcunfu/DevEnv/releases/latest)。
2. 打开启动器，进入「内置工具 → 环境 → 熔岩环境」。
3. 页面菜单栏提供「目录」（应用目录 / 下载缓存 / 数据目录）、「工具」（环境变量）与「帮助」（官方文档），下方页签切换服务、软件下载、活动下载、下载历史、镜像、扫描与数据目录。

## 主界面

- **菜单栏**：「目录」菜单含应用目录、下载缓存、数据目录；「工具」菜单含环境变量；「帮助」菜单打开官方文档。
- **页签**：服务、软件下载、活动下载、下载历史、镜像、扫描、数据目录。
- **中间**：绿色版服务进程列表，可对每项执行启动/停止。
- **底部**：左侧打开本帮助文档，右侧点击版本号查看关于信息。

JSON 格式化、Hosts 编辑等小工具请从启动器内容区（内置工具）打开；Windows 管理程序入口在启动器顶部「系统工具」菜单。

## 数据目录

熔岩模块的下载与绿色版软件默认放在与主程序相同的数据根目录（可在「工具 → 数据目录」中查看/修改）：

```
文档\FNSoftware\DevEnv\     （默认；实际路径见「工具 → 数据目录」）
├── data.json               # 主程序业务数据 / 偏好
├── icons\                  # 主程序图标缓存
├── apps\                   # 各软件绿色包
├── cache\                  # 下载缓存
├── config.json             # 熔岩应用配置
└── ...
```

首次使用建议先打开 **镜像配置**，按需设置 pip / npm 等国内镜像，再使用 **软件下载**。
