# 熔岩剪贴板 · 快速开始

「熔岩剪贴板」内嵌于 DevEnv 左侧 **熔岩剪贴板** Tab（原独立 Clipboard 应用），自动记录文本与图片剪贴板历史。

## 功能

- **自动监听**：启动 DevEnv 后即在后台轮询剪贴板（可点「关闭监听」暂停）
- **历史列表**：按时间范围、类型（文本/图片）与关键词过滤
- **预览与操作**：选中条目查看文本或图片；双击复制，或右键左侧列表 / 右侧详情选择「复制」「删除」
- **清空 / 导出**：清空记录可选择清空文本或图片，再按全部 / 今天 / 昨天 / 前天执行；导出当前可见文本历史
- **保留策略**：只保留最近 3 天的记录。启动时以及运行中每小时检查一次，自动删除更早的数据库记录与对应图片文件，避免长期复制占满磁盘
- **状态栏**：窗口底部左侧常驻显示总数、文本数、图片数与保留天数，右侧显示复制 / 删除 / 清空 / 导出等操作结果，数秒后自动隐藏
- **打开入口**：单击托盘图标打开快捷应用，点击窗口顶部左侧的「剪贴板」方形入口；不再注册全局快捷键

## 数据目录

用户数据在 DevEnv 用户数据目录下的 `文档\FNSoftware\DevEnv\Clipboard\`

| 文件 / 目录 | 说明 |
|-------------|------|
| `config.json` | 模块配置 |
| `clipboard.db` | SQLite 历史库 |
| `clipboard_images/` | 图片文件 |

启动时会自动迁移旧位置（旧版 `文档\FNSoftware\Clipboard\`、程序目录或 `data/`）中的数据。

## 与独立版差异

嵌入 DevEnv 后：

- 不再使用独立托盘 / 开机自启 / 应用内自更新（由 DevEnv 统一管理）
- 关于信息见 DevEnv「设置」
- 从快捷应用窗口顶部的入口打开独立窗口，不再占用 `Ctrl+Space`
- 代码高亮预览简化为纯文本 + 语言识别标签
