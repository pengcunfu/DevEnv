# 网络监控 · 快速开始

「网络监控」从启动器「内置工具 → 监控 → 网络监控」打开独立窗口（原独立 NetworkWatch 应用），按进程展示 TCP/UDP 连接与上下行速率。端口管理与网络测速已拆成同组下的独立工具。

## 主界面

- **进程列表**：显示进程名、PID、连接数、下载/上传速率
- **连接详情**：双击进程行打开独立窗口，查看其本地/远程端点、状态与上下行速率，可手动刷新（进程退出或没有连接时会提示）
- **搜索**：按进程名、PID 或可执行路径过滤
- **暂停 / 立即刷新**：暂停自动刷新，或手动采集一次快照
- **状态栏摘要**：连接数、总下载、总上传与当前模式提示显示在工具窗底部状态栏，关闭窗口后自动清空

## 端口管理

从启动器「内置工具 → 监控 → 端口管理」打开，列出本机连接，支持：

- 按端口、地址、进程过滤
- 约 2 秒自动刷新
- 结束占用该连接的进程（可能需要管理员权限）

## 网络测速

从启动器「内置工具 → 监控 → 网络测速」打开，使用公共测速节点测量延迟、下载与上传速度。可随时取消；失败时会尽量保留上次成功结果。

## 管理员模式

普通权限下部分进程的 ETW 流量统计可能不完整。点击 **管理员重启** 会以 `runas` 重启 **当前 DevEnv 进程**（UAC 可取消，取消后继续普通权限运行）。

提权会影响整个 DevEnv（与 Hosts 编辑提权同类取舍）。已是管理员时，按钮变为降权重启。
