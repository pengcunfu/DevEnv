# 功能概览

## 开发环境管理

把需要常驻的开发服务收进一个列表，按需启动 / 停止（配置保存在 `data.json` 的 `DevServiceList`）：

- **自定义服务**：添加、编辑、移除；名称、工作目录、启动命令、停止命令与进程名都可配置
- **后台运行**：启动命令通过 `cmd /c` 执行，`npm run dev`、批处理与带参数的 exe 都能直接填
- **状态识别**：本程序拉起的进程实时显示运行状态；填写「进程名」后，重启本程序也能识别并停止它
- **停止方式**：优先执行停止命令让服务优雅退出，失败时结束进程树
- **工作目录**：可逐个指定；留空时使用用户数据目录，命令里用相对路径也不会跑错位置
- **运行日志**：每个服务的标准输出与错误输出实时写入「日志」窗口，同时落盘到 `文档\FNSoftware\DevEnv\logs\`；停止后与重启程序后仍可回看上一次运行记录。日志自动识别 UTF-8 与系统 ANSI 代码页，PostgreSQL 等按 GBK 输出的中文不会乱码；窗口内带行号并自动折行

## 系统工具

全局启动器的第四个页签，按类别整理常用 Windows 工具，减少在「运行」或控制面板中查找：

| 分类 | 示例 |
|------|------|
| 系统管理 | 计算机管理、服务、系统配置、注册表、环境变量 |
| 硬件与设备 | 设备管理器、磁盘管理、显示/声音/电源 |
| 网络与安全 | 防火墙、本地安全策略、网络连接 |
| 性能与监控 | 任务管理器、资源监视器、事件查看器、计划任务 |

JSON 格式化器、Hosts 文件编辑器、图像格式转换器、文件哈希计算器、文件解锁与粉碎等实用工具在全局启动器的 **内置工具** 页签，单击各自打开独立窗口；启动项管理与右键菜单管理也在这个页签，同页还有「燧岚开发盒子」入口，点击直接显示主窗口。

::: tip Hosts 编辑
首次打开 **Hosts 文件编辑器** 时会弹出 UAC。确认后会以管理员身份临时拉起编辑窗口（主 DevEnv 进程仍保持普通权限）。

编辑器会实时校验 Hosts 语法与条目：无效 IP、缺少主机名、非法主机名、重复条目、同一主机名映射冲突等会在底部汇总，可展开问题列表并点击定位到对应行。
:::

## 文件解锁与粉碎

从「工具 → 文件解锁与粉碎」打开独立窗口：

- **解除占用**：通过 Windows Restart Manager 找出正在使用某个文件 / 文件夹的进程，可按需结束这些进程（关键系统进程与当前程序自身受保护）
- **文件粉碎**：用随机数据覆盖文件 1 / 3 / 7 遍后删除，支持拖入文件和整个文件夹；不可恢复
- 粉碎前会校验路径，拒绝磁盘根目录、Windows / Program Files 等系统关键目录，以及包含当前程序的目录

详见 [文件解锁与粉碎 · 快速开始](./filetools/getting-started.md)。

## 应用程序管理

**单独按一下 `Win` 键**或从托盘右键菜单「全局启动器…」打开 Launchpad 式全屏启动器：本地应用 / 文件夹 / 网站 / 系统工具 / 内置工具是五个横向页签，顶部搜索框跨五类合并匹配，中部大图标网格，单击图标即启动，`Esc` 关闭，`←` / `→` 或 `Ctrl` + 鼠标滚轮切换页签，启动器打开时再按一次 `Win` 收起。点击空白处不再关闭窗口，拖动空白可框选多个图标（`Ctrl` + 单击切换选中）；拖动图标可调整顺序，把图标拖到另一个图标的图标中心会合并成启动器文件夹，点击文件夹磁贴展开内容，右键可重命名或解散。把 `.exe` 或文件夹拖入主窗或启动器即可添加，右键图标可运行、定位、改名、刷新图标与移除。

::: tip Win 键拦截
`Win+E`、`Win+R`、`Win+D`、`Win+Tab` 等组合键**不受影响**，只是单独按 Win 键不再弹出系统开始菜单。需要开始菜单时可按 `Ctrl+Esc`；想改回系统行为，到「设置 → 快捷键」取消勾选「单独按一下 Win 键打开全局启动器」。
:::

- **本地应用**：将 `.exe` **拖入**程序即可保存路径与图标；支持多选添加、卡片单击启动
- **文件夹**：拖入目录作为快捷方式，可设**别名**与自定义图标，单击在资源管理器中打开（不重命名真实文件夹）
- **网站**：输入网址自动获取标题与 favicon，可改显示标题和图标，单击在浏览器打开
- **启动即驻留托盘**：程序启动时不弹出任何窗口，只在后台常驻托盘；需要主窗口时按 `Ctrl+Alt+D`（可在「设置 → 快捷键」修改）或从托盘右键菜单「显示主窗口」唤出
- **无边框窗口 + 托盘**：无系统标题栏；右上角仅关闭按钮（隐藏到托盘）；**单击托盘图标**或按 `Alt+Space`（可在「设置 → 快捷键」修改）打开快捷应用（搜索并启动应用 / 文件 / 命令，同时可搜索全局启动器里的本地应用、文件夹与网站；窗口顶部另有剪贴板 / 翻译 / 开发环境 / 文件浏览器入口，开发环境直接唤回主窗口），**右键托盘图标**弹出菜单——「显示主窗口」进入主窗口、「设置…」打开设置对话框（含关于与帮助）、「全局启动器…」打开图标启动台，「退出」才真正结束程序
- **快捷操作**：运行、在资源管理器中显示、移除应用

## 熔岩环境

内嵌于左侧 **熔岩环境** Tab（原独立「熔岩 / DevEnv」应用），面向绿色版本地服务：

- **进程管理**：MySQL / Redis / Nginx 等一键启停，无需注册 Windows 服务
- **软件下载**：内置源下载 zip / 7z 等并解压到应用目录
- **环境扫描与镜像**：检测本机运行时，配置 pip / npm 等镜像
- **工具菜单**：环境变量、应用目录、数据目录等快捷入口（JSON / Hosts 等小工具从全局启动器的「内置工具」页签打开）

详见 [熔岩环境 · 快速开始](./lava/getting-started.md)。

## 熔岩翻译

内嵌于左侧 **熔岩翻译** Tab：

- WebView2 打开有道 / 搜狗 / 百度 / 谷歌 / DeepL / 必应 / 腾讯等站点
- **快捷应用顶部入口**：打开翻译窗时，剪贴板有内容会自动填入当前站点；不再占用全局快捷键
- 配置目录：`%USERPROFILE%\.lava_translator\`

详见 [熔岩翻译 · 快速开始](./translator/getting-started.md)。

## 网络监控

内嵌于左侧 **网络监控** Tab：

- 按进程监控 TCP/UDP 连接与上下行速率
- 网络测速、端口管理、进程详情
- 可选管理员模式以完善 ETW 流量统计（会重启整个 DevEnv）

详见 [网络监控 · 快速开始](./networkwatch/getting-started.md)。

## 进程监控

内嵌于左侧 **进程监控** Tab：

- 实时刷新进程 CPU%、工作集内存、线程数与路径
- 按名称 / PID / 路径搜索；按 CPU、内存或名称排序
- 结束进程、结束进程树、在资源管理器中定位可执行文件

详见 [进程监控 · 快速开始](./processwatch/getting-started.md)。

## 服务监控

内嵌于左侧 **服务监控** Tab（位于「进程监控」下方），用来替代系统自带的 `services.msc`：

- 列出 Windows 服务的显示名、服务名、状态、启动类型、登录身份与描述
- 按状态筛选、按显示名 / 服务名 / 状态排序，支持搜索
- 启动、停止、重启、暂停 / 继续，以及修改启动类型（自动 / 自动延迟 / 手动 / 禁用）
- 查看服务的可执行文件、依赖服务与被依赖服务；需要管理员权限时可一键管理员重启
- 系统工具里的「服务」入口改为打开该页，不再拉起系统服务面板

详见 [服务监控 · 快速开始](./servicewatch/getting-started.md)。

## 熔岩剪贴板

内嵌于左侧 **熔岩剪贴板** Tab：

- 自动记录文本 / 图片剪贴板历史（SQLite）
- 搜索、分类与时间范围过滤；清空与导出
- 从快捷应用窗口顶部的「剪贴板」入口打开；不再占用全局快捷键

详见 [熔岩剪贴板 · 快速开始](./clipboard/getting-started.md)。
