# 功能概览

## 开发环境管理

从启动器「内置工具 → 环境 → 开发环境」打开独立窗口，把需要常驻的开发服务收进一个列表，按需启动 / 停止（配置保存在 `data.json` 的 `DevServiceList`）：

- **自定义服务**：添加、编辑、移除；名称、工作目录、启动命令、停止命令与进程名都可配置
- **后台运行**：启动命令通过 `cmd /c` 执行，`npm run dev`、批处理与带参数的 exe 都能直接填
- **菜单栏**：「服务」菜单提供添加服务、刷新与打开日志目录；「视图」菜单可在表格视图与卡片视图之间切换，选择会记住；卡片视图固定每行三列，随窗口宽度均分
- **状态识别**：定时轮询实际进程；填写「进程名」时按名字识别，留空时从启动命令推断（如 `redis-server.exe`、`bin\postgres`），并按工作目录校验。外部启动或重启本程序后仍在运行的 Redis / PostgreSQL / MySQL 等不会再误报「已停止」；npm / node / python 等共享进程无法区分时请手动填写进程名
- **停止方式**：优先执行停止命令让服务优雅退出，失败时结束进程树；按推断出的进程名停止时只处理工作目录内的进程，避免误杀同名程序
- **工作目录**：可逐个指定；留空时使用用户数据目录，命令里用相对路径也不会跑错位置
- **运行日志**：每个服务的标准输出与错误输出实时写入「日志」窗口，同时落盘到 `文档\FNSoftware\DevEnv\logs\`；停止后与重启程序后仍可回看上一次运行记录。日志自动识别 UTF-8 与系统 ANSI 代码页，PostgreSQL 等按 GBK 输出的中文不会乱码；窗口内带行号并自动折行

## 系统工具

启动器左侧「系统工具」页签按分类标签分组展示常用 Windows 工具（上方标签、下方图标），减少在「运行」或控制面板中查找：

| 分类 | 示例 |
|------|------|
| 系统管理 | 计算机管理、服务、系统配置、注册表、环境变量 |
| 硬件与设备 | 设备管理器、磁盘管理、显示/声音/电源 |
| 网络与安全 | 防火墙、本地安全策略、网络连接 |
| 性能与监控 | 任务管理器、资源监视器、事件查看器、计划任务 |

启动器左侧「内置工具」页签按分类展示：「环境」含开发环境与熔岩环境；「监控」含网络监控、进程监控、服务监控、端口管理与网络测速；「窗口入口」含熔岩翻译、熔岩剪贴板与文件浏览器；「实用工具」含 JSON 格式化器、Hosts 编辑器、图像转换、文件哈希、编码工具箱、文件解锁与粉碎、C 盘清理、启动项管理与右键菜单管理，以及正则测试器、文本对比、批量重命名、颜色工具与系统信息。单击各自打开独立窗口，彩色图标与系统工具一眼可区分。

::: tip Hosts 编辑
首次打开 **Hosts 文件编辑器** 时会弹出 UAC。确认后会以管理员身份临时拉起编辑窗口（主 DevEnv 进程仍保持普通权限）。

编辑器顶部有「定位到文件」「在记事本中打开」「环境变量」；支持「文本编辑」与「按条编辑」（表格增删改 IP / 主机名，写回时保留注释与空行）。会实时校验 Hosts 语法与条目：无效 IP、缺少主机名、非法主机名、重复条目、同一主机名映射冲突等会在底部汇总，可展开问题列表并点击定位到对应行。
:::

::: tip 右键菜单管理
窗口分「已有菜单」「自定义项」两个页签。「已有菜单」按文件 / 文件夹 / 文件夹空白处 / 桌面 / 文件与文件夹筛选系统里已注册的菜单项，同时列出 shell 命令项与 COM 扩展，显示启用状态、来源、命令或 DLL；可启用 / 禁用、删除（删除前自动导出 `.reg` 备份，HKLM 项会请求管理员）或复制注册表路径。「自定义项」编辑显示名称、注册表键名、程序路径与文件 / 文件夹 / 文件夹空白处 / 桌面作用域；「保存配置」只写本地 JSON，「应用更改」会提权写入注册表。顶部「工具」菜单可刷新、切换 Win11 一级 / 完整二级菜单并检查环境。
:::

::: tip 编码工具箱
从「内置工具 → 实用工具 → 编码工具箱」打开。顶部菜单打开 Base64 / URL / Hex / Unicode / HTML、AES / XOR、哈希与 Unix 时间工具；每个工具是可关闭页签，左右为输入 / 输出。Base64 另支持文本 / 图片 / 文件模式。
:::

::: tip 常用小工具
- **正则测试器**：校验 .NET 正则表达式，列出每处匹配的位置、长度与捕获组，支持忽略大小写、多行与单行选项，`Ctrl+Enter` 直接匹配。
- **文本对比**：逐行比较两段文本，标出新增与删除行，可忽略大小写与空白差异。
- **批量重命名**：对文件夹顶层文件统一加前后缀、查找替换、转换大小写或追加序号；先预览重名与非法字符冲突，确认后再落盘。
- **颜色工具**：HEX / RGB / HSL 互转，滑杆调色、随机取色并生成同色系明暗色板，颜色值可一键复制。
- **系统信息**：按页签查看操作系统、计算机、处理器、内存、磁盘、显卡与网络适配器快照，支持手动刷新与复制全部。
:::

## 文件解锁与粉碎

从「工具 → 文件解锁与粉碎」打开独立窗口：

- **解除占用**：通过 Windows Restart Manager 找出正在使用某个文件 / 文件夹的进程，可按需结束这些进程（关键系统进程与当前程序自身受保护）
- **文件粉碎**：用随机数据覆盖文件 1 / 3 / 7 遍后删除，支持拖入文件和整个文件夹；不可恢复
- 粉碎前会校验路径，拒绝磁盘根目录、Windows / Program Files 等系统关键目录，以及包含当前程序的目录

详见 [文件解锁与粉碎 · 快速开始](./filetools/getting-started.md)。

## C 盘清理

从启动器「内置工具 → 实用工具 → C 盘清理」打开独立窗口：

- **一键扫描**：列出用户临时文件、Windows 临时文件、Windows 更新缓存、预读取文件、缩略图缓存、DirectX 着色器缓存、Internet 临时文件、崩溃转储、Edge / Chrome 浏览器缓存与回收站的占用大小
- **按需清理**：勾选要清理的项目后一键删除；会带来重新下载或首次启动变慢的项目（更新缓存、预读取）默认不勾
- **安全边界**：不跟随符号链接与目录联接，跳过当前程序所在目录；被占用或权限不足的文件自动跳过，单个失败不影响整批
- **权限提示**：普通权限下系统目录会被标记「需要管理员」，可从窗口内一键以管理员身份重启
- **回收站**：通过系统 Shell API 清空 C 盘回收站，执行前会在确认框中明确提示

详见 [C 盘清理 · 快速开始](./diskcleaner/getting-started.md)。

## 应用程序管理

**单独按一下左 `Alt` 键**、单击托盘图标、右键「显示主窗口」或 `Ctrl+Alt+D` 打开产品主窗口——使用 Windows 默认窗口边框与标题栏的 Launchpad 式启动器（默认 960 × 680 DIP、水平垂直居中，可用系统标题栏最大化 / 最小化；最小化后从左 Alt、托盘或任务栏还原，内容配色与 Windows 11 开始菜单一致并跟随系统浅 / 深色，打开与收起直接显示、隐藏，不播放整窗动画）：左侧栏自上而下是搜索框与本地应用 / 文件夹 / 网站 / 系统工具 / 内置工具 / 开始菜单六个纵向页签，右侧是大图标网格；搜索框跨六类合并匹配，单击图标即启动，`Esc` 关闭，`←` / `→` 或 `Ctrl` + 鼠标滚轮切换页签，启动器打开时再按一次左 `Alt` 收起。往「本地应用」添加 `.exe` 时会自动在系统开始菜单的「燧岚开发盒子」文件夹里创建同名快捷方式，移除时同步删除；反过来，「开始菜单」页签只读展示系统开始菜单里的应用（按一级文件夹分组），已经收进启动器的条目自动隐藏，右键可启动、定位或「添加到启动器」。点击空白处不再关闭窗口，拖动空白可框选多个图标（`Ctrl` + 单击切换选中）；拖动图标可调整顺序，把图标拖到另一个图标的图标中心会合并成启动器文件夹，点击文件夹磁贴会在居中的浮层卡片里展开内容（不占满启动器），点击卡片外的空白处或按 `Esc` 收起，右键可重命名或解散。把 `.exe` 或文件夹拖入主窗或启动器即可添加，右键图标可运行、定位、改名、刷新图标与移除。换页时卡片会按顺序错峰浮入，鼠标悬停卡片会轻微放大，文件夹浮层与页签选中都带回弹动画。

::: tip 左 Alt 拦截
`Alt+Tab`、`Alt+F4`、`Alt+空格` 等组合键**不受影响**，程序也不会吞掉左 Alt 的按下与抬起，所以前台程序不会把 `Alt` 误判成一直按着；单独按左 Alt 时前台窗口的菜单栏会被点亮一下，这是 Windows 原本的行为。想改回系统行为，到「设置 → 快捷键」取消勾选「单独按一下左 Alt 键打开启动器」。

启动器与开始菜单互斥：开始菜单开着时按左 Alt，会先收起开始菜单再显示启动器；启动器显示期间按 `Win` 想打开开始菜单时，启动器会先自动收起，不会把开始菜单压在下面。
:::

- **本地应用**：将 `.exe` **拖入**程序即可保存路径与图标；支持多选添加、卡片单击启动
- **文件夹**：拖入目录作为快捷方式，可设**别名**与自定义图标，单击在资源管理器中打开（不重命名真实文件夹）。「文件夹」页与资源管理器**快速访问双向同步**：快速访问里固定的目录会自动出现，启动器里添加 / 移除文件夹时也会同步固定 / 取消固定；在资源管理器里取消固定的条目会从启动器移除（手动添加且从未同步的条目不受影响）。文件夹图标与资源管理器保持一致（含文件夹属性里的自定义图标），右键「刷新图标」可重新读取
- **网站**：输入网址自动获取标题与 favicon，可改显示标题和图标，单击在浏览器打开
- **启动即驻留托盘**：程序启动时不弹出任何窗口，只在后台常驻托盘；需要主窗口（启动器）时按 `Ctrl+Alt+D`（可在「设置 → 快捷键」修改）、单击托盘或右键「显示主窗口」唤出。开发环境、熔岩环境与各监控类工具从启动器左侧「内置工具」页签进入，各自打开独立窗口
- **托盘**：**单击托盘图标**打开主窗口（启动器），左 `Alt` 键切换启动器显示；`Ctrl+Space` 打开熔岩剪贴板、`Alt+Space` 打开熔岩翻译（均可在「设置 → 快捷键」修改）；**右键托盘图标**弹出菜单——「显示主窗口」「设置…」「熔岩翻译」「熔岩剪贴板」「文件快速预览…」「文件浏览器…」「区域截图」「退出」；语音与截屏相关入口在「设置 → 语音与截屏」
- **快捷操作**：运行、在资源管理器中显示、移除应用

## 熔岩环境

从启动器「内置工具 → 环境 → 熔岩环境」打开独立窗口（原独立「熔岩 / DevEnv」应用），面向绿色版本地服务：

- **进程管理**：MySQL / Redis / Nginx 等一键启停，无需注册 Windows 服务
- **软件下载**：内置源下载 zip / 7z 等并解压到应用目录
- **环境扫描与镜像**：检测本机运行时，配置 pip / npm 等镜像
- **菜单栏**：「目录」菜单打开应用目录、下载缓存与数据目录；「工具」菜单打开环境变量；「帮助」菜单打开官方文档（JSON / Hosts 等小工具从启动器左侧「内置工具」页签打开）

详见 [熔岩环境 · 快速开始](./lava/getting-started.md)。

- **全局热键**：按 `Alt+Space`（可在「设置 → 快捷键」修改）打开翻译窗，剪贴板有内容会自动填入当前站点；也可从托盘右键菜单「熔岩翻译」打开
- 配置目录：`文档\FNSoftware\DevEnv\Translator\`

详见 [熔岩翻译 · 快速开始](./translator/getting-started.md)。

## 网络监控

从启动器「内置工具 → 监控 → 网络监控」打开独立窗口：

- 按进程监控 TCP/UDP 连接与上下行速率
- 双击进程查看连接详情
- 可选管理员模式以完善 ETW 流量统计（会重启整个 DevEnv）

端口管理与网络测速已拆成同组下的独立工具入口。

## 进程监控

从启动器「内置工具 → 监控 → 进程监控」打开独立窗口：

- 实时刷新进程 CPU%、工作集内存、线程数与路径
- 按名称 / PID / 路径搜索；按 CPU、内存或名称排序
- 结束进程、结束进程树、在资源管理器中定位可执行文件

详见 [进程监控 · 快速开始](./processwatch/getting-started.md)。

## 服务监控

从启动器「内置工具 → 监控 → 服务监控」打开独立窗口，用来替代系统自带的 `services.msc`：

- 列出 Windows 服务的显示名、服务名、状态、启动类型、登录身份与描述
- 按状态筛选、按显示名 / 服务名 / 状态排序，支持搜索
- 启动、停止、重启、暂停 / 继续，以及修改启动类型（自动 / 自动延迟 / 手动 / 禁用）
- 双击或点「详情」打开模态框，查看可执行文件、依赖服务与被依赖服务，并可修改启动类型；需要管理员权限时可一键管理员重启
- 系统工具里的「服务」入口改为打开该工具窗，不再拉起系统服务面板

详见 [服务监控 · 快速开始](./servicewatch/getting-started.md)。

## 启动项管理

从启动器「内置工具 → 实用工具 → 启动项管理」打开独立窗口：

- 列出当前用户 Run 注册表与启动文件夹中的开机启动项
- 表格显示类型、来源、发布者、文件说明、版本、解析后的可执行文件与文件状态
- 启动文件夹中的快捷方式会解析目标与参数；注册表命令会展开环境变量
- 文件缺失或只有命令名（如 `rundll32.exe`）时会在状态列标出，便于清理失效启动项
- 顶部「启动项」菜单提供添加与刷新；在任意启动项上右键可删除，或在右键菜单中刷新
