# 服务监控 · 快速开始

「服务监控」内嵌于 DevEnv 左侧导航（位于 **进程监控** 下方），用来替代 Windows 自带的 `services.msc` 服务面板。

## 主界面

- **服务列表**：显示名、服务名、状态、启动类型、登录身份与描述
- **搜索**：按显示名、服务名、描述、登录身份或可执行路径过滤
- **筛选**：全部状态 / 运行中 / 已停止
- **排序**：按显示名、服务名或状态排序（运行中的服务优先）
- **自动刷新**：约每 3 秒刷新一次，可「暂停刷新」或「立即刷新」
- **服务详情**：选中一行后，底部显示描述、可执行文件、登录身份、服务类型、依赖服务与被依赖服务

## 操作

选中一个服务后可以：

- **启动 / 停止 / 重启**：停止与重启会先确认；依赖它的服务仍在运行时，会提示先停止依赖项
- **暂停 / 继续**：仅对支持暂停的服务可用
- **修改启动类型**：自动、自动（延迟启动）、手动、禁用，点「应用」后生效
- **打开目录**：在资源管理器中定位服务的可执行文件
- **管理员重启**：状态栏显示「普通权限」时，一键以管理员身份重启 DevEnv

::: tip 权限说明
读取服务列表不需要管理员权限；**启动、停止、重启、暂停与修改启动类型**需要管理员权限。若操作提示权限不足，先点工具条右侧的「管理员重启」，在弹出的 UAC 提示中确认后重试。
:::

## 与系统工具「服务」的关系

全局启动器左侧「系统工具」页签里的 **服务** 入口现在直接打开内置的服务监控页，不再拉起系统的 `services.msc`。设备驱动不在列表中；驱动管理仍请使用设备管理器。
