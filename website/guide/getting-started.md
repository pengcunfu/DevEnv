# 快速开始

## 下载与安装

1. 打开 [GitHub Releases](https://github.com/pengcunfu/DevEnv/releases/latest)
2. 下载 **DevEnv-<ver>-win-x64.zip**（Windows 64 位便携包）
3. 目标机安装 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（程序不携带运行时）
4. 解压到任意可写目录（例如 `D:\Tools\DevEnv`），运行 `DevEnv.exe`

::: tip
程序是便携版，解压即用。打开「设置 → 关于与帮助」可检查并自动升级；Office 结构化预览、OCR 与语音引擎在第一次使用或「设置 → 服务与模型」中按需下载。
:::

## 运行

解压后运行 `DevEnv.exe`（进程名 `DevEnv`）。启动后不弹出任何窗口，只在托盘常驻——单击托盘图标或按左 `Alt` 键打开全局启动器，`Ctrl+Space` 打开熔岩剪贴板、`Alt+Space` 打开熔岩翻译，右键菜单「显示主窗口」进入开发窗口、「设置…」打开设置对话框（含关于与帮助）、「全局启动器…」打开图标启动台，`Ctrl+Alt+D` 也可以唤回开发窗口（快捷键均可在「设置 → 快捷键」修改）。主界面分为两个窗口：**开发窗口**（开发环境 / 熔岩环境，从托盘或快捷键进入）与 **监控窗口**（网络监控 / 进程监控 / 服务监控，从全局启动器左侧「内置工具」页签里的「FireNeb Monitor」进入）。首次运行会在用户文档目录生成数据：

`文档\FNSoftware\DevEnv\`

| 文件 | 说明 |
|------|------|
| `data.json` | 主程序业务数据与偏好（托盘、自启等） |
| `config.json` | 熔岩环境模块配置 |
| `icons\` | 应用/网站图标缓存 |
| `logs\` | 开发环境服务的运行日志 |

::: tip
用户数据保存在文档目录，升级 / 重装不会丢失。
:::

## 界面概览

- **全局启动器**：单独按一下左 `Alt` 键或从托盘右键菜单「全局启动器…」打开固定 960 × 680 DIP、水平垂直居中的启动器（使用 Windows 默认窗口边框与标题栏，内容配色与 Windows 11 开始菜单一致并跟随系统浅 / 深色，打开与收起直接显示、隐藏），左侧栏是搜索框与「本地应用 / 文件夹 / 网站 / 系统工具 / 内置工具 / 开始菜单」六个纵向页签，右侧是图标网格；单击图标即启动，`Esc` 关闭，`←` / `→` 或 `Ctrl` + 鼠标滚轮切换页签；空白处拖拽框选多个图标，拖动图标调整顺序，拖到另一个图标中心可合并成文件夹；把 `.exe` 或文件夹拖入主窗 / 启动器即可添加，添加本地应用时会同步在系统开始菜单创建快捷方式；「开始菜单」页签只读展示系统开始菜单里的应用，已收进启动器的条目自动隐藏
- **托盘与全局热键**：单击托盘图标或按左 `Alt` 键打开全局启动器；`Ctrl+Space` 直接打开熔岩剪贴板、`Alt+Space` 直接打开熔岩翻译（并自动填充剪贴板文本）；应用、文件与命令的搜索启动继续由全局启动器提供，快捷键可在「设置 → 快捷键」统一修改
- **开发环境**：自定义后台服务的配置、启停与目录访问
- **熔岩环境**：绿色版进程管理、软件下载与镜像配置（见 [熔岩快速开始](./lava/getting-started.md)）
- **熔岩翻译**：网页翻译站，按 `Alt+Space` 或从托盘右键菜单打开（见 [翻译快速开始](./translator/getting-started.md)）
- **网络监控**：按进程查看连接与速率、测速与端口管理（见 [网络监控快速开始](./networkwatch/getting-started.md)）
- **进程监控**：实时 CPU / 内存、搜索排序与结束进程（见 [进程监控快速开始](./processwatch/getting-started.md)）
- **服务监控**：Windows 服务启停、启动类型与依赖查看，替代系统服务面板（见 [服务监控快速开始](./servicewatch/getting-started.md)）
- **熔岩剪贴板**：文本/图片历史，按 `Ctrl+Space` 或从托盘右键菜单打开（见 [剪贴板快速开始](./clipboard/getting-started.md)）
- **设置**：从托盘右键菜单「设置…」打开，包含常规选项、快捷键、语音与截屏、服务与模型，以及「关于与帮助」页（产品信息、检查更新与帮助文档入口）

## 常见问题

**SmartScreen / 杀毒软件拦截？**  
未签名安装器可能被 Windows SmartScreen 提示，选择「仍要运行」即可；可添加信任或使用 [从源码构建](./build.md) 自行编译。

**需要 32 位版本？**  
当前 Release 仅提供 win-x64；如有需求可在 [Issues](https://github.com/pengcunfu/DevEnv/issues) 中反馈。
