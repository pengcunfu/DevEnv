# 快速开始

## 下载与安装

1. 打开 [GitHub Releases](https://github.com/pengcunfu/DevEnv/releases/latest)
2. 下载 **DevEnv-<ver>-win-x64.zip**（Windows 64 位便携包）
3. 目标机安装 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（程序不携带运行时）
4. 解压到任意可写目录（例如 `D:\Tools\DevEnv`），运行 `DevEnv.exe`

::: tip
程序是便携版，解压即用。打开「设置 → 关于与帮助」可检查并自动升级；Office 结构化预览、OCR 与语音引擎在第一次使用或「设置 → 服务与模型」中按需下载。
:::

## 运行

解压后运行 `DevEnv.exe`（进程名 `DevEnv`）。启动后直接显示**主窗口（启动器）**；收起后驻留托盘，可用单击托盘图标、右键「显示主窗口」或 `Ctrl+Alt+D` 重新打开，`Ctrl+Space` 打开熔岩剪贴板、`Alt+Space` 打开熔岩翻译，主界面菜单栏的「设置」打开设置对话框（含关于与帮助；快捷键均可在「设置 → 快捷键」修改）。开发环境、熔岩环境、网络 / 进程 / 服务监控、端口管理、网络测速等功能都从启动器内容区（内置工具）以**独立窗口**打开，Windows 系统工具从启动器顶部「系统工具」菜单打开。首次运行会在用户文档目录生成数据：

`文档\FNSoftware\DevEnv\`

| 文件 | 说明 |
|------|------|
| `data.json` | 主程序业务数据与偏好（托盘、自启等） |
| `config.json` | 熔岩环境模块配置 |
| `icons\` | 应用/网站图标缓存 |
| `logs\` | 开发环境服务的运行日志 |

::: tip
用户数据保存在文档目录，升级 / 重装不会丢失。
:::

## 界面概览

- **主窗口（启动器）**：单击托盘、右键「显示主窗口」或 `Ctrl+Alt+D` 打开默认 960 × 680 DIP、水平垂直居中的启动器（使用 Windows 默认窗口边框与标题栏，可最大化 / 最小化，内容配色与 Windows 11 开始菜单一致并跟随系统浅 / 深色，打开与收起直接显示、隐藏），顶部菜单栏的「系统工具」按分类收纳全部 Windows 工具，下方是按分类分组的内置工具图标网格；单击图标或菜单项即启动，`Esc` 关闭，`F5` 刷新
- **本地应用 / 文件夹 / 网站 / 开始菜单窗口**：从启动器「内置工具 → 窗口入口」打开，各自是普通非模态窗口（可最小化、不因失焦收起）。在对应窗口里把 `.exe` 或文件夹拖入即可添加，空白处拖拽框选多个图标，拖动图标调整顺序，拖到另一个图标中心可合并成文件夹；添加本地应用时会同步在系统开始菜单创建快捷方式，文件夹窗口还会与资源管理器快速访问双向同步（固定的目录自动导入，添加 / 移除时同步固定 / 取消固定），网站图标优先复用 Edge 收藏夹里的 favicon；开始菜单窗口只读展示系统开始菜单里的应用，已收进启动器的条目自动隐藏
- **托盘与全局热键**：单击托盘打开主窗口；`Ctrl+Space` 打开熔岩剪贴板、`Alt+Space` 打开熔岩翻译（并自动填充剪贴板文本）；快捷键可在「设置 → 快捷键」统一修改
- **开发环境**：自定义后台服务的配置、启停与目录访问
- **熔岩环境**：绿色版进程管理、软件下载与镜像配置（见 [熔岩快速开始](./lava/getting-started.md)）
- **熔岩翻译**：网页翻译站，按 `Alt+Space` 或从托盘右键菜单打开（见 [翻译快速开始](./translator/getting-started.md)）
- **网络监控**：按进程查看连接与速率（见 [网络监控快速开始](./networkwatch/getting-started.md)）
- **端口管理 / 网络测速**：各自独立工具窗，从「内置工具 → 监控」进入
- **进程监控**：实时 CPU / 内存、搜索排序与结束进程（见 [进程监控快速开始](./processwatch/getting-started.md)）
- **服务监控**：Windows 服务启停、启动类型与依赖查看，替代系统服务面板（见 [服务监控快速开始](./servicewatch/getting-started.md)）
- **熔岩剪贴板**：文本/图片历史，按 `Ctrl+Space` 或从托盘右键菜单打开（见 [剪贴板快速开始](./clipboard/getting-started.md)）
- **设置**：从主窗口菜单栏的「设置」打开，包含常规选项、快捷键、语音与截屏、服务与模型，以及「关于与帮助」页（产品信息、检查更新与帮助文档入口）

## 常见问题

**SmartScreen / 杀毒软件拦截？**  
未签名安装器可能被 Windows SmartScreen 提示，选择「仍要运行」即可；可添加信任或使用 [从源码构建](./build.md) 自行编译。

**需要 32 位版本？**  
当前 Release 仅提供 win-x64；如有需求可在 [Issues](https://github.com/pengcunfu/DevEnv/issues) 中反馈。
