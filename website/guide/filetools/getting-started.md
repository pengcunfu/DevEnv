# 文件解锁与粉碎 · 快速开始

从菜单「工具 → 文件解锁与粉碎」打开独立窗口，窗口内分「解除占用」与「文件粉碎」两个页签。两者都是本地操作，不上传文件内容。

## 解除占用

用于删除、改名或覆盖文件时遇到「文件正在被另一个程序使用」的场景。

1. 选择或输入文件 / 文件夹路径（也可直接点击「浏览文件…」「浏览文件夹…」）
2. 点击「检测占用」
3. 在列表中查看占用进程：进程名、PID、应用类型、启动时间与可执行文件路径
4. 选中进程后点击「结束所选进程」，或点击「结束全部可结束进程」

检测基于 Windows 官方 Restart Manager（`rstrmgr.dll`），默认不需要管理员权限。扫描文件夹时会递归检查其中的文件；超过 2000 个文件时只检测前 2000 个，界面会给出提示。

::: warning
「解除占用」通过**结束占用进程**释放文件，不会只关闭单个句柄。结束进程可能导致未保存的数据丢失，请先确认对方没有正在编辑的内容。关键系统进程与 DevEnv 自身会显示为不可结束。
:::

如果部分进程检测不到或结束失败，通常是权限不足：点击提示行右侧的「以管理员身份重启」，确认 UAC 后 DevEnv 会以管理员身份重新启动，当前打开的工具窗口会关闭。

## 文件粉碎

用于在删除敏感文件前尽可能覆盖其内容。粉碎后**无法恢复**。

1. 点击「添加文件…」「添加文件夹…」，或把文件 / 文件夹直接拖进窗口
2. 也可以在输入框中填写完整路径后回车
3. 选择覆盖遍数：
   - **1 遍（快速）**：日常清理
   - **3 遍（推荐）**：默认
   - **7 遍（严格）**：更慢，适合高度敏感数据
4. 点击「开始粉碎」，仔细阅读确认框后确认

粉碎过程会：

- 递归枚举文件夹内容（不会沿符号链接 / 目录联接进入目标目录）
- 清除只读属性，用密码学随机数生成器产生的数据覆盖文件内容
- 每遍写入后刷盘，完成后把文件截断为 0 字节
- 把文件改成随机名称后删除，再自底向上删除空目录

进度条按「文件大小 × 覆盖遍数」计算；单个文件失败（例如仍被占用、权限不足）不会中断整批任务，失败项和原因会显示在窗口底部。粉碎进行中可以点击「取消」——已经覆盖的文件不会恢复，未处理的文件会保留。

::: tip 仍被占用？
如果粉碎失败并提示「可能仍被占用」，先切到「解除占用」页签检测并结束占用进程，再回到粉碎列表重试。失败的文件会保留在列表中。
:::

## 安全边界

为避免误操作，以下路径会被直接拒绝粉碎：

- 磁盘 / UNC 根目录（如 `C:\`）
- Windows、System32、Program Files、Program Files (x86)、ProgramData、用户主目录等系统关键目录本身
- 包含当前运行程序的目录
- 符号链接与目录联接（避免误删链接指向的外部内容）

## 局限

粉碎只能保证覆盖当前文件所在的逻辑扇区：

- SSD 的 TRIM、磨损均衡与主控缓存可能在物理层面保留旧数据
- 文件系统日志、卷影副本、系统还原点与云盘同步可能保存历史版本
- 已删除文件的历史痕迹不在本工具处理范围内

对极高敏感数据，建议同时使用全盘加密（BitLocker 等），并注意同步盘与备份中的副本。
