# C 盘清理 · 快速开始

从启动器左侧「内置工具 → 实用工具 → C 盘清理」打开独立窗口。工具只清理系统与常见程序的临时文件、缓存，不上传任何文件，也不会改动文档、桌面或程序安装目录。

## 使用方式

1. 打开窗口后会自动扫描一次；也可以随时点「扫描 C 盘」重新扫描
2. 顶部卡片显示 C 盘可用空间与已用比例
3. 在列表中查看各清理项的大小、文件数、权限与状态
4. 勾选要清理的项目（可点「全选」「全不选」快速调整）
5. 点「清理所选」，阅读确认框后确认

清理过程中会显示当前清理项、已处理文件数与进度。完成后自动重新扫描，列表会反映实际释放后的占用。

## 清理项

| 分类 | 清理项 | 说明 |
|------|--------|------|
| 临时文件 | 用户临时文件 | 当前用户 `%TEMP%`，安装包解压与程序运行残留 |
| 临时文件 | Windows 临时文件 | 系统级临时目录，需要管理员权限 |
| 系统缓存 | Windows 更新缓存 | 已下载的更新安装包，删除后需要时重新下载，默认不勾 |
| 系统缓存 | 预读取文件 | 常用程序启动信息，删除后首次启动稍慢，默认不勾 |
| 系统缓存 | 缩略图缓存 | 资源管理器缩略图数据库，会自动重建 |
| 系统缓存 | DirectX 着色器缓存 | 图形程序编译的着色器缓存 |
| 系统缓存 | Internet 临时文件 | 系统组件与浏览器共享的网页缓存 |
| 系统缓存 | 崩溃转储与错误报告 | `CrashDumps`、`Minidump` 与 Windows 错误报告队列 |
| 浏览器缓存 | Edge / Chrome 浏览器缓存 | 只清理缓存与着色器缓存，不影响书签、密码与历史记录 |
| 回收站 | 回收站 | 清空 C 盘回收站，删除后无法恢复 |

浏览器缓存建议先关闭对应浏览器，否则正在使用的缓存文件会被跳过。

## 安全边界

- 只清理内置的固定目录，不接受任意路径
- 拒绝磁盘根目录、Windows、Program Files、ProgramData、用户目录等系统关键目录
- 不跟随符号链接与目录联接，避免清到链接指向的外部内容
- 跳过当前程序所在目录；把便携版解压到临时目录时也不会误删自身
- 被占用或权限不足的文件直接跳过并计入「已跳过」，不会中断整批清理
- 清理只删除目录内容，保留缓存目录本身，程序下次运行会自动重建

::: tip 需要管理员权限
Windows 临时文件、Windows 更新缓存、预读取文件等系统目录在普通权限下会被标记「需要管理员」。点击「以管理员身份重启」，确认 UAC 后 DevEnv 会以管理员身份重新启动，当前打开的工具窗口会关闭。
:::

## 常见问题

**清理后占用没有明显变化？**
浏览器、系统服务或正在运行的程序可能仍占用缓存文件。关闭相关程序后再扫描一次；更新缓存与预读取文件在普通权限下会被跳过。

**回收站清空后还能恢复吗？**
不能。清空回收站前请确认没有需要还原的文件。

**会删除下载、文档或桌面文件吗？**
不会。工具只处理上表中的临时目录与缓存目录，不扫描用户文档、桌面、下载等个人目录。
